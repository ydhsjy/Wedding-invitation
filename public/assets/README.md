File aset yang dipakai undangan:

- `awal.jpeg` untuk tampilan awal sebelum undangan dibuka.
- `kanan awal.jpeg` untuk foto pertama pada halaman utama.
- `utama kiri.jpeg` untuk background desktop sebelah kiri.
- `bg1.jpeg` untuk background ayat/kutipan.
- `bg2.jpeg` untuk background pemberkatan nikah.
- `bg3.jpeg` untuk background resepsi.
- `Groom.jpg` untuk foto mempelai pria.
- `Bride.jpeg` untuk foto mempelai wanita.
- `ending.jpeg` untuk foto penutup paling terakhir.
- `gallery-1.jpeg` sampai `gallery-6.jpeg` untuk galeri.
- `assetsmusicmp3.mp3` untuk musik latar.

Jika ingin memakai foto mempelai yang berbeda dari galeri, tambahkan file baru
dan ubah bagian `.person__image--bride` atau `.person__image--groom` di
`styles.css`.
